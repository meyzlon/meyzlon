## 🎯 Como Usar

### 1️⃣ Ver Saldo do Mês
1. Clique em **"📈 Relatórios"**
2. Veja o card **"💰 Saldo Mensal"** no topo
3. Valores destacados em 3 cores:
   - Verde = Entradas
   - Vermelho = Saídas
   - Azul = Saldo (resultado)

### 2️⃣ Trocar Período
1. No card de saldo, tem um dropdown "Período selecionado:"
2. Clique e escolha um mês
3. Todos os números e gráficos mudam automaticamente

### 3️⃣ Mudar Tipo de Gráfico (Gastos)
1. No gráfico **"Gastos"**, veja o dropdown no canto
2. Opções:
   - **📊 Coluna** (padrão) - Ver gastos comparados
   - **📈 Linha** - Ver se gastos estão subindo
   - **🍩 Rosca** - Ver proporção de gastos
3. Clique para mudar - gráfico atualiza na hora

### 4️⃣ Mudar Tipo de Gráfico (Saldo)
1. No gráfico **"Saldo"**, veja o dropdown no canto
2. Opções:
   - **📈 Linha** (padrão) - Ver se saldo sobe/desce
   - **📊 Coluna** - Comparar cada mês
   - **📐 Área** - Ver acumulação visual
3. Clique para mudar

### 5️⃣ Ver Entradas por Categoria
1. Role para baixo em **"Relatórios"**
2. Veja a seção **"Entradas por Categoria"**
3. Mostra um gráfico onde veio cada entrada
4. Tem um card com **"Total de Entradas: R$ X,XX"** destacado
5. Pode mudar tipo com dropdown:
   - **📊 Coluna** - Ver valores
   - **📈 Linha** - Ver evolução
   - **🥧 Pizza** - Ver proporção

## 💡 Exemplos Práticos

### Exemplo 1: "Quanto entrou no mês?"
1. Vá para **Relatórios**
2. Veja o card de saldo:
   - Valor de **Entradas** (verde)
3. Ou vá para seção "Entradas por Categoria"
4. Veja o **Total de Entradas** destacado

### Exemplo 2: "Meu saldo está melhorando?"
1. Vá para **Relatórios**
2. Veja gráfico de **Saldo**
3. Mude para **"📈 Linha"**
4. Se a linha sobe → saldo melhorando
5. Se a linha desce → saldo piorando

### Exemplo 3: "Onde veio meu dinheiro?"
1. Vá para **Relatórios**
2. Role até **"Entradas por Categoria"**
3. Escolha visualizar como **"📊 Coluna"**
4. Vê quais categorias trouxeram mais dinheiro
5. Se mudar para **"🥧 Pizza"**, vê a proporção

### Exemplo 4: "Como foram os gastos?"
1. Vá para **Relatórios**
2. Veja gráfico de **"Gastos"**
3. Já vem em **"📊 Coluna"** (padrão)
4. Pode mudar para ver de forma diferente:
   - **"📈 Linha"** - Se está tendência de aumento
   - **"🍩 Rosca"** - Proporção de gastos

## 🚀 Dicas de Uso

### 💡 Dica 1: Use Coluna para Comparar
Se quer saber qual mês teve mais gasto, use **Coluna** - as barras são fáceis de comparar.

### 💡 Dica 2: Use Linha para Tendência
Se quer saber se os gastos estão aumentando ou diminuindo, use **Linha** - a inclinação mostra a tendência.

### 💡 Dica 3: Use Pizza para Proporção
Se quer saber qual categoria consome mais, use **Pizza** - o tamanho da fatia mostra a proporção.

### 💡 Dica 4: Mude o Período
Escolha diferentes meses para comparar seus gastos ao longo do tempo.

### 💡 Dica 5: Analise as Entradas
Veja qual categoria traz mais dinheiro - te ajuda a entender suas fontes de renda.

## ❓ Dúvidas Frequentes

### P: Posso voltar ao gráfico anterior?
**R:** Sim! Mude o dropdown para outro tipo e depois volte ao anterior.

### P: Os dados mudam automaticamente?
**R:** Sim! Quando você cria uma nova transação, os relatórios atualizam.

### P: Posso comparar dois meses?
**R:** No momento não há comparação lado a lado, mas pode trocar o mês e anotar os valores.

### P: Qual tipo de gráfico é melhor?
**R:** Depende do que quer ver:
- **Coluna** = Comparar valores
- **Linha** = Ver tendência
- **Pizza** = Ver proporção

### P: Por que o total de entradas aparece em destaque?
**R:** Para facilitar ver rapidamente quanto entrou naquele período.
